# МТР Экстрактор

Веб-инструмент для автоматического извлечения позиций из каталогов поставщиков и подготовки данных к загрузке в корпоративный справочник МТР.

---

## Зачем этот инструмент

При кодировании новых МТР сотрудник вручную переносит данные из PDF-каталога поставщика в шаблон Excel. Это занимает часы на каждый каталог и приводит к ошибкам.

МТР Экстрактор делает это автоматически: принимает каталог, читает его через искусственный интеллект и возвращает готовую таблицу, которую остаётся только проверить и загрузить.

---

## Как это работает — шаг за шагом

```
Пользователь загружает каталог (PDF или фото)
        ↓
Файл отправляется на сервер
        ↓
Сервер передаёт файл в Claude AI (Anthropic)
        ↓
Claude «читает» документ и возвращает структурированный список позиций
        ↓
Сервер проверяет качество данных и отдаёт результат браузеру
        ↓
Пользователь видит таблицу, редактирует при необходимости
        ↓
Нажимает «Выгрузить в Excel» — получает файл в нужном шаблоне
```

---

## Из чего состоит инструмент

Инструмент состоит из двух частей, которые работают вместе.

### 1. Интерфейс (то, что видит пользователь в браузере)

Обычная веб-страница. Пользователь перетаскивает файл, нажимает кнопку, видит таблицу с результатами и скачивает Excel. Никаких установок и регистраций — открыл ссылку и работаешь.

### 2. Сервер (невидимая часть)

Небольшая программа, которая:
- Принимает файл от браузера
- Отправляет его в Claude AI с инструкцией «извлеки все позиции и верни в формате JSON»
- Получает ответ, проверяет его корректность
- Возвращает данные браузеру

API-ключ к Claude AI хранится только на сервере — пользователь его не видит и не вводит.

---

## Что умеет Claude AI в этом контексте

Claude — это языковая модель от Anthropic (аналог ChatGPT, но через API). В данном инструменте он используется как «умный читатель»: получает изображение или PDF и извлекает из него таблицу с нужными полями:

| Поле | Что содержит |
|---|---|
| Единица измерения | ШТ, КГ, М и т.д. |
| Наименование МТР | Полное техническое название |
| Марка / Размер | Тип, модель, типоразмер |
| Каталожный номер | Артикул производителя |
| ГОСТ / ТУ | Номер стандарта, если указан |
| Техн. характеристика | Все параметры: мощность, давление, габариты и пр. |

---

## Формат выгрузки

Скачиваемый Excel точно соответствует шаблону «НН МТР массовое кодирование»:
- Двойная строка заголовков (как в оригинальном шаблоне)
- Поля «Класс МТР», «Код класса» и «Причина создания» оставлены пустыми — их заполняет пользователь вручную перед загрузкой в систему

---

## Где развёрнут

Сервер работает на платформе **Railway** — это облачный хостинг, который автоматически обновляет приложение при каждом изменении кода в репозитории GitHub.

```
GitHub (код) → Railway (сервер) → Браузер пользователя
```

---

## Ограничения

- Один файл за раз (можно загружать несколько последовательно — результаты суммируются)
- Очень большие каталоги (сотни страниц) лучше разбивать на части
- Качество извлечения зависит от читаемости документа: сканы с низким разрешением или нестандартными форматами таблиц могут дать неполный результат
- Все извлечённые данные рекомендуется проверить перед загрузкой в справочник
